好，各位同學我們繼續上次的內容。今天要講的是 color model，也就是色彩模型。大家看投影片第八頁，我們平常拍的彩色照片，每一個 pixel 有三個 channel，分別是 R、G、B。三個 channel 的照片佔的 memory 比較大，處理起來也比較慢。所以很多時候，我們會先把 RGB 照片轉成灰階照片，灰階照片每個 pixel 只有一個 channel，計算就快很多。轉換的方法是把 R、G、B 乘上不同的權重再加起來，因為人眼對綠色最敏感，所以綠色的權重最大。除了 RGB 以外，另一個很常用的是 HSV，H 是色相，S 是飽和度，V 是亮度。HSV 比較接近人類感知顏色的方式，所以在做膚色偵測或是物體追蹤的時候特別好用。下禮拜的作業，請大家用 Python 和 OpenCV，把一張照片從 RGB 轉成 HSV，再把 H、S、V 三個 channel 分別畫出來，下禮拜二上課前上傳到 Moodle。
